# MediaTracker — Автономная версия для VS Code (Live Server) и GitHub Pages

## Особенности сборки:
1. **Точный дизайн и функционал из архива v3.0 (`style.css` и `app.js`)**: сохранены все экраны со скриншотов (Каталог, Фильтры, Детальная карточка, Вход/Регистрация с быстрым выбором ролей, Личный кабинет зрителя, Админ-панель с жалобами и управлением администраторами, Передача аккаунта).
2. **База данных на 30 карточек (`js/db.js` и `db.json`)**:
   - 10 сериалов (*Во все тяжкие, Чернобыль, Прослушка, Игра престолов, Клан Сопрано, Шерлок, Лучше звоните Солу, Настоящий детектив, Тьма, Очень странные дела*);
   - 10 аниме (*Атака титанов, Стальной алхимик: Братство, Фрирен, Аркейн, Врата Штейна, Тетрадь смерти, Ковбой Бибоп, Монстр, Клинок, рассекающий демонов, Токийский гуль*);
   - 10 фильмов (*Побег из Шоушенка, Крестный отец, Темный рыцарь, Криминальное чтиво, Начало, Бойцовский клуб, Дюна: Часть вторая, Интерстеллар, Матрица, Унесенные призраками*).
3. **Постеры `<img>` + папка `img/`**: каждая карточка загружает обложку через тег `<img>` с автоматическим переключением на локальный постер `img/poster-1.svg ... img/poster-30.svg`.
4. **Запуск без Node.js сервера**:
   - Откройте папку в **Visual Studio Code** и запустите `index.html` через **Live Server** (или просто откройте `index.html` двойным кликом в браузере).
   - Для публикации на **GitHub Pages** просто загрузите все файлы репозитория в ветку `main` и включите GitHub Pages в настройках.
